# JomJalan Travel Agency
JomJalan Travel Agency is a desktop application developed using Electron, HTML, CSS and JavaScript.

## Features
- Explore travel destinations
- Display weather information
- Recommend activities based on weather conditions
- Display public holidays
- View travel packages
- Calculate estimated travel budgets
- Save, edit and delete travel plans

## Technologies Used
- HTML
- CSS
- JavaScript
- Electron
- JSON
- LocalStorage
- External APIs
